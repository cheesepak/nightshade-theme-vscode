# Nightshade VS Code Theme

Collection of three vibrant themes for Visual Studio Code each named after a plant in the Nightshade family. Grab it from the [VSCode Marketplace](https://marketplace.visualstudio.com/items?itemName=SirCheese.nightshade)!

## Themes

- **Wolfsbane**: Midnight blue dark theme
- **Belladonna**: Green-forward dark theme
- **Datura**: Green-forward light theme
